- **Phạm vi**: ExerciseService, ProgressService, CodeRunnerService, ClassService, AuthService, UserService, LessonService, TopicService, FavoriteService, SettingService + SubmissionLockRegistry + entities + controllers.

## Tổng kết

- **Tổng findings: 24** — CAO: **4** | TRUNG: **12** | THẤP: **8**

### Điểm mạnh đã xác nhận
- Transaction đúng chỗ: SubmitAsync (submission + UserProgress + UserNodeProgress trong 1 tx), SubmitCodeAsync, RefreshAsync rotation, ResetPasswordAsync, Verify2FaCodeAsync đều có BeginTransactionAsync.
- Unique constraints DB đầy đủ cho các bảng upsert/join quan trọng (UserProgress, UserNodeProgress, ClassMember, Favorite, ContentFeedback, RefreshToken, PasswordResetToken, User.Email, Topic, Setting).
- Refresh token replay detection tuần tự (PreviousTokenHash) hoạt động với replay tuần tự.
- SubmitAsync validate đầy đủ lớp/ladder/đáp án trước khi ghi.

### Rủi ro chính (thứ tự ưu tiên sửa)
1. **Refresh rotation TOCTOU (#3)** — lỗ hổng phiên thực tế, cần UPDLOCK/điều kiện update.
2. **Double-submit qua multi-instance (#1)** + race upsert progress → 500/ghi trùng.
3. **Race check-then-insert trả 500 (#2, #4, #11-14)** — UX lỗi + log 500 nhiễu; fix chung bằng translate DbUpdateException.
4. **Không RowVersion (#7)** — mất trạng thái Passed trong race.
5. **Cache stale Settings (#17, #18)** — policy lệch khi multi-instance.
