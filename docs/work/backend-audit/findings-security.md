## Verified OK (không phải finding)

- **Raw SQL** (`GamificationService.cs:136,183,318,350,505,867` — `ExecuteSqlInterpolatedAsync`): 100% tham số hóa, không nối chuỗi → **không SQL injection**.
- **Password hashing**: PBKDF2-SHA256 100.000 vòng + salt 16 byte (`Common/PasswordHasher.cs:13-22`) — chuẩn.
- **JWT**: HS256, ValidateIssuer/Audience/Lifetime/SigningKey, `MapInboundClaims=false`, ClockSkew 1 phút hợp lý; access 60 phút / refresh 7 ngày — hợp lý cho đồ án.
- **Refresh rotation**: rotate-invalidate + replay → thu hồi cả chuỗi (trừ race #4) — thiết kế đúng.
- **CORS**: `WithOrigins(allowedOrigins)` + `AllowCredentials`, mặc định `AllowedOrigins: []` (appsettings.json:11) — **không AllowAnyOrigin**; dev chỉ `localhost:5173`. An toàn.
- **RBAC/ownership**: không tìm thấy IDOR qua userId từ route/body — Me/Progress-me/Favorites/CodeRuns/Achievements đều dùng `CurrentUserId()` từ token; Progress report (ProgressService.cs:121-124), Classes (ClassService.CanManage), Exercises submissions (ExerciseService.CanManage) đều có ownership check; UsersController có primary-admin + last-admin rules.
- **Log**: không log password/secret/access token thô; RequestLoggingMiddleware không log body/header (chỉ method/path/status/duration).
- **Error handling**: ErrorHandlingMiddleware ẩn chi tiết exception ngoài Development.
- **2FA bật** bắt buộc qua OTP; forgot-password trả thông báo chung; reset token 30 phút single-use.
