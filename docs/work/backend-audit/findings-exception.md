## Điểm đạt chuẩn (xác nhận qua đọc code)

- **Result pattern đúng cho lỗi kỳ vọng**: AuthController (17/17 action), GamificationController (16/16), ExerciseService (NOT_FOUND/FORBIDDEN/EXERCISE_CLOSED/SUBMISSION_IN_PROGRESS/LADDER_LOCKED/VALIDATION_FAILED đều qua `Result.Fail`) — không ném exception cho lỗi nghiệp vụ; Service cấm Repository pattern tuân thủ (DbSet trực tiếp).
- **Log đúng 1 lần tại boundary**: ErrorHandlingMiddleware.cs:39 là điểm LogError duy nhất cho exception unhandled; log kèm CorrelationId/RequestId qua LogContext (RequestLoggingMiddleware wrap `next()` trong scope — middleware nằm sau nên property có hiệu lực), `X-Correlation-Id` set header trước khi chạy pipeline nên có cả trên response lỗi.
- **Không leak nội bộ ra production**: production chỉ trả message generic; exception.Message/type chỉ trong `IsDevelopment()` (ErrorHandlingMiddleware.cs:56-60); không log request/response body (tránh nhạy cảm); path log không kèm query string.
- **OperationCanceledException xử lý đúng**: không log lỗi, không trả response (ErrorHandlingMiddleware.cs:32-36); startup fatal log kèm `Log.CloseAndFlush` (Program.cs:184-195).
- **ErrorCodes catalog tập trung** + `GetHttpStatus` map chuẩn, envelope thống nhất cho mọi lỗi Result.
